Este documento .md tiene escrito todo lo que debes seguir para generar el sitio web deseado que servira como base para la Hackathon de Space Apps Uruguay el dia 14 y 15 de noviembre. El desafio elegido es el desafio 4, del cual ya hay contexto proporcionado en desafio.md

La idea base esta plasmada en el archivo figma. Deberas usar ese archivo para entender hacia donde queremos dirigir el rumbo del proyecto, y en base a eso construiras la primera version de la web. El figma tiene medidas muy especificas y no comunes, por lo tanto, deberas usar los skills de diseño que ya tenes descargados para el desarollo del front-end y ajustar las medidas para que queden numeros redondos, comunes, y no medidas muy especificas de padding por ejemplo. 

Lo que diseñes debera cumplir estrictamente con los objetivos planteados, haciendo un buen uso de las fuentes de informacion proporcionadas.  Ademas, en conjunto, deberas crear un archivo de reglas para todos los agentes que trabajen con el repositorio. Las reglas son las siguientes:  
  
-Trabajar en ramas, commits explicados a detalle
-Documentar cada decision junto a su solucion.
-Consultar con el equipo si un cambio no esta muy claro o si la informacion es vaga/escasa
